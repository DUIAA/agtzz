# 《微光森林》(Glimmerwood)

一个可以在手机浏览器直接玩的单机 RPG 冒险游戏。

## 这是什么游戏？

你是一名在森林边缘醒来、失去记忆的少年/少女。探索微光森林，与村民和旅人交谈，击败怪物，找回你的过去。

- 🗺️ 2D 俯视角探索
- ⚔️ 回合制战斗
- 💬 NPC 对话与任务
- 📱 手机友好，支持触摸操作

## 如何启动游戏

**最简单的方式：**
1. 把项目文件夹下载到手机
2. 用手机浏览器打开 `index.html`
3. 开始游戏！

**或者：**
- 直接把 `index.html` 拖到电脑浏览器里打开
- 用手机访问 GitHub Pages（见下方）

## 手机运行方法

### 方法一：直接打开本地文件
1. 将 `agtzz/` 文件夹传到手机
2. 用文件管理器找到 `index.html`
3. 选择"用浏览器打开"

### 方法二：通过局域网访问（电脑先运行）
```bash
# 在电脑上的项目目录运行
python3 -m http.server 8080
```
然后手机浏览器访问 `http://你的电脑IP:8080`

## 操作说明

- **电脑：** 方向键移动，空格/回车确认
- **手机：** 点击屏幕左侧虚拟方向键移动，点击右侧按钮确认/攻击
- **对话：** 靠近 NPC 按确认键
- **战斗：** 选择攻击/防御/道具/逃跑
